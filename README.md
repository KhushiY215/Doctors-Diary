# Doctors-Diary
An AI Assistant for Preliminary Diagnosis.

Doctor’s Diary is a web-based clinical documentation platform developed to streamline how healthcare professionals record, organize, and access patient notes. Designed for small to mid-sized clinical practices, it offers a fast, offline-capable alternative to traditional electronic health record (EHR) systems. The platform provides essential features such as note creation, report generation, and historical record access, wrapped in a lightweight interface that minimizes complexity and maximizes usability.
